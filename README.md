# BubbleBandit

## Daks Mobile Car Wash - Hive Network

Welcome to Daks Mobile Car Wash, a professional mobile car wash service that's part of the Hive Network. This website provides information about our services and allows customers to book appointments.

### Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Service Listings**: Clear presentation of all available car wash packages
- **Online Booking**: Easy-to-use booking form for scheduling services
- **About Section**: Information about Daks and the Hive Network
- **Contact Information**: Multiple ways to reach us

### Services Offered

1. **Basic Wash** - $29.99
2. **Premium Wash** - $49.99
3. **Deluxe Detail** - $89.99
4. **Ultimate Package** - $149.99

### How to Use

Simply open `index.html` in a web browser to view the website. The site is a single-page application with smooth scrolling navigation between sections:

- Home
- Services
- About
- Contact/Booking

### Technologies Used

- HTML5
- CSS3 (with responsive design)
- JavaScript (vanilla JS for interactivity)
